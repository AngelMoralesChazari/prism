===========================================================
               PRISM v1.0.0 - GUIA DE INSTALACION
===========================================================

OPCION RECOMENDADA (INSTALADOR NATIVO CON JAVA INTEGRADO):
Si descargaste Prism-1.0.0-Setup.exe, ejecutalo y sigue el
asistente grafico (Siguiente -> Instalar). No requiere
configuracion manual ni instalar Java por separado.

-----------------------------------------------------------
OPCION DE PAQUETE ZIP (INSTALADOR GRAFICO INCLUIDO)
-----------------------------------------------------------
REQUISITO PREVIO PARA EL PAQUETE ZIP:
Tener instalado Java (OpenJDK 17 o superior).
Si no lo tienes, descargalo gratis desde: https://adoptium.net

PASO 1: INSTALAR EL LENGUAJE Y COMPILADOR (prc)
1. Haz doble clic en el archivo:
   Instalar-Prism-Grafico.bat
   (Tambien puedes usar install.bat si prefieres consola).

2. En la ventana grafica, deja activada la casilla:
   "Agregar Prism (prc) al PATH del sistema (Recomendado)"
   y haz clic en "Instalar ahora >".

3. Abre una nueva ventana de PowerShell o CMD y escribe:
   prc --version

-----------------------------------------------------------
PASO 2: INSTALAR LA EXTENSION EN TU IDE (OPCIONAL)
-----------------------------------------------------------
En la carpeta extensions\ encontraras los plugins para:
- VS Code: extensions\prism-vscode-1.0.2.vsix
  (Extensiones -> ... -> Install from VSIX...)
- IntelliJ IDEA: extensions\prism-intellij-1.0.0.zip
- Eclipse IDE: extensions\prism-eclipse-1.0.0.jar
- Apache NetBeans: extensions\prism-netbeans-1.0.0.zip

-----------------------------------------------------------
COMANDOS RAPIDOS PARA PROBAR EN TU TERMINAL:
-----------------------------------------------------------
- Ejecutar un archivo:
  prc run examples\prueba_nl.pr

- Compilar a un archivo .class ejecutable:
  prc compile examples\prueba_nl.pr -d out\

- Ejecutar el programa compilado:
  java -cp "out;%LocalAppData%\Programs\Prism\lib\prism.jar" prueba_nl
